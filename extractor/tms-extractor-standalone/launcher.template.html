TMS Extractor standalone

ดึง Picking List พร้อมชื่อ Item ออกเป็น CSV / Excel / JSON — ไม่ต้องรัน server ล็อคอินด้วยรหัสของคุณเอง

ทำไมต้องวางใน Console ไม่ใช่เปิดไฟล์ HTML เฉย ๆ
API ของ TMS ไม่ส่ง header Access-Control-Allow-Origin (ทดสอบแล้ว) เบราว์เซอร์จึงบล็อกทุก request ที่มาจาก origin อื่น รวมถึงไฟล์ที่เปิดจากเครื่องคุณเอง

ทางที่ไม่ต้องมี server คือให้โค้ดทำงาน บน origin ของ TMS เอง — same-origin ไม่ติด CORS แอปทั้งตัวจึงมาในรูปโค้ดชุดเดียวที่วางใน Console แล้วเด้งเป็นหน้าจอเต็ม

5 รายงาน Actual Shipment



  ปุ่มสลับบนสุดของแผงซ้ายเปลี่ยนเป็นโหมด Actual Shipment ได้ — ดึงจาก
  POST /v1/reports/actualshipment ออกมาเป็น 23 คอลัมน์ ลำดับเดียวกับรายงานของ TMS


  Trip Date ค่าเริ่มต้นคือเมื่อวาน เพราะข้อมูลของวันปัจจุบันยังไม่ actual
  รอบข้อมูลปิดและส่งหลังเที่ยงคืน หน้า TMS ก็ตั้งค่าเริ่มต้นแบบเดียวกัน


  ติ๊ก "ดึงชื่อ item มาด้วย" แล้วแอปจะไป join กับ pickinglistheaders
  ด้วยเลข PL แล้วแตกเป็น 1 แถว = 1 item ต่อคอลัมน์ Item No / Item Name / Item Qty
  ท้าย 23 คอลัมน์เดิม (รายงานของ TMS ไม่มีชื่อ item ให้เลย)


  ได้ตารางแบนล้วน ไม่มีแถวรวมยอดคั่น เอาไปทำ pivot ต่อได้ทันที ยอดรวมดูจากการ์ดสถิติด้านบน


  ค่าที่ไม่ได้อยู่ระดับแถวจะเขียนครั้งเดียวแล้วเว้นว่างที่เหลือ — unit ระดับ PL,
  actualCost ระดับ trip ถ้าปล่อยให้ซ้ำ ลาก sum ใน Excel ยอดจะบวม


  ไฟล์เป็น .xlsx จริง Excel จึงไม่เตือนเรื่องฟอร์แมตตอนเปิด




6 3 มุมมอง (โหมด Picking List)



  
    
    
  • รายการ — 1 แถว = 1 item. PL ที่มี 3 item แตกเป็น 3 แถว. เหมาะกับเอาไปทำ pivot
    • 
    
  • สรุปราย PL — 1 แถว = 1 PL พร้อมจำนวน item, qty รวม, รายชื่อ item ทั้งหมด
    • 
    
  • สรุปราย Item — 1 แถว = 1 item code พร้อม qty รวม, จำนวน PL, สัดส่วน % พร้อมแถบเทียบ
    • 
  

  คลิกหัวคอลัมน์เพื่อเรียง · ช่องค้นกรองทุกคอลัมน์ · แบ่งหน้าได้


  Export — CSV (UTF-8 BOM เปิด Excel อ่านไทยได้), Excel (.xlsx จริง ตัวเลขเป็น number), JSON

  ออกทั้งชุดตามมุมมองและคำค้นที่เปิดอยู่ ไม่ตัดตามหน้าที่แสดง




7 ความปลอดภัย



  
    
    
  • รหัสผ่านถูกส่งไป POST /tms-api/api/tokens ของเซิร์ฟเวอร์ TMS ตัวจริงเท่านั้น แล้วเคลียร์ออกจากฟอร์มทันที
    • 
    
  • token อยู่ในหน่วยความจำของแท็บ ไม่เขียนลง localStorage ไม่เขียนลงไฟล์ ปิดแท็บแล้วหาย
    • 
    
  • ทุก endpoint เป็น read-only: /tokens, /personal/profile,
        /personal/warehouses, /v1/pickinglistheaders/{wh}/search
    • 
    
  • ไม่มีโค้ดส่วนไหน POST / PUT / DELETE ข้อมูลจริงในระบบ TMS
    • 
    
  • UI อยู่ใน shadow DOM แยกขาดจาก Angular ของ TMS — ไม่กวน state ของหน้าเดิม
    •
