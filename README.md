# TMS Web

ระบบติดตามงานขนส่งสำหรับรถของบริษัทเอง ช่วยตอบสองคำถามที่ฝ่ายจัดรถเจอทุกวันโดยไม่ต้อง
โทรถามคนขับ — **รถอยู่ตรงไหน** และ **ส่งของถึงลูกค้าแล้วหรือยัง**

## ใช้งานอะไรได้บ้าง

- **ดึงงานจากระบบ TMS หลักของบริษัท** มาแปลงเป็นงานที่ส่งถึงมือถือคนขับได้ทันที
- **ฝั่งคนขับ** เปิดมือถือแล้วเห็นรายการจุดส่งของแต่ละเที่ยวครบ เลือกลำดับเข้าส่งเอง
  ปิดงานทีละจุด พร้อมถ่ายรูปและให้ลูกค้าเซ็นรับของผ่านแอปได้เลย
- **ฝั่งฝ่ายจัดรถ/สำนักงาน** เห็นภาพรวมว่างานไหนถึงมือคนขับแล้ว งานไหนยังรออยู่
  รถแต่ละคันอยู่ตรงไหน โดยไม่ต้องโทรถามใคร
- **ฝั่งคลัง/สำนักงาน** เปิดเมนูพิมพ์ใบส่งสินค้าก่อนรถออก ดู Trip สถานะ Confirm และ Handling
  พร้อมพิมพ์เอกสารทั้ง Trip, แยกทุก Ship To หรือเลือกพิมพ์ Ship To เดียวได้
- **เก็บหลักฐานการส่งของ** ครบทุกใบงาน ทั้งลายเซ็น รูปถ่าย พิกัด และเวลา แก้ไขไม่ได้อีกหลัง
  ยืนยันแล้ว
- **ฝั่งผู้ดูแลระบบ** จัดการบัญชีผู้ใช้ สิทธิ์การเข้าถึง ข้อมูลรถ และรายชื่อพนักงานขับ

## พิมพ์ใบส่งสินค้าก่อนรถออก

หน้า **พิมพ์ใบส่งสินค้า** อ่าน Trip และรายการ Shipment จาก TMS ตอนเปิดหน้า และกรองตามช่วงวันที่
กับคลัง แสดงเฉพาะ Trip ที่สถานะ `Confirm` หรือ `Handling` เมนูนี้อ่านข้อมูลอย่างเดียว
ไม่เปลี่ยนข้อมูลใน TMS

ก่อนเรียกพิมพ์ หน้าแสดงประเภทเอกสารจากคำนำหน้า Shipment ID ทั้งระดับ Trip และ Ship To:

- `PL` แสดงเป็น **Dealer**
- `BK` แสดงเป็น **Transfer**
- หากใน Trip หรือ Ship To เดียวกันมีทั้ง `PL` และ `BK` แสดง **Dealer + Transfer**
- หากไม่พบคำนำหน้าที่รู้จัก แสดง **ไม่ระบุ**

ประเภทเอกสารแสดงบนหน้าข้อมูลก่อนพิมพ์เท่านั้น ไม่เพิ่มลงในเอกสาร A4 โดยมีตัวเลือกพิมพ์ทั้ง Trip
เป็นเอกสารเดียว, พิมพ์แยกทั้งหมดเป็นเอกสารราย Ship To หรือพิมพ์ Ship To ที่เลือก

## สถานะการใช้งาน

ใช้งานจริงกับกองรถของบริษัททุกวัน ครบทั้งแอปคนขับ หลักฐานการส่งของ การติดตามตำแหน่งรถแบบสด
และการรับงานจากระบบ TMS หลัก
