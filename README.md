# 🚛 TMS — Transport Management System

ระบบบริหารจัดการขนส่งแบบครบวงจร สำหรับบริษัทขนส่งที่มีรถเป็นของตัวเอง
ตั้งแต่รับออเดอร์ → วางแผนจัดคิว → มอบหมายรถ/คนขับ → ติดตามสถานะ → รายงานผล

**ธีมองค์กร Aurora v5 (ขาวอมม่วง + periwinkle + violet + rose quartz) · Sans ตัวเดียวทั้งระบบ (ลำดับชั้นจากน้ำหนัก) · UI ภาษาไทย · Animation ลื่นไหล (CSS-only) · รันได้บนเครื่องเก่า (2016+)**

| **ข้อมูล CSV** | ข้อมูลจริงเก็บที่ฐานข้อมูล **จัดการผ่านหน้าเว็บเท่านั้น** — ระบบเขียน **ไฟล์ CSV 9 ไฟล์ (export)** ให้อัตโนมัติทุกครั้งที่ข้อมูลเปลี่ยน (เปิด/วิเคราะห์ใน Excel ได้) · หน้า "ข้อมูล CSV" ดูสถานะ + **ดาวน์โหลดทีละไฟล์** + กดรีเฟรชไฟล์ใหม่ |

### Workflow สถานะ
```
ออเดอร์: รอจัดคิว → จัดคิวแล้ว → กำลังขนส่ง → ส่งสำเร็จ   (ยกเลิกได้ก่อนเริ่มเดินทาง)
เที่ยว:   วางแผนแล้ว → กำลังขนส่ง → เสร็จสิ้น
```
- สร้างเที่ยว = **จองรถ/คนขับทันที** (ห้ามซ้ำซ้อน, เช็คความจุ, น้ำหนักเกินแจ้งเตือน)
- เสร็จ/ยกเลิกเที่ยว = ปล่อยรถ/คนขับคืนว่างอัตโนมัติ + อัปเดตสถานะออเดอร์ทั้งทริปใน **transaction เดียว**
- เก็บ POD ได้เมื่อออเดอร์ส่งสำเร็จเท่านั้น (บังคับฝั่ง server) · ยืนยัน POD แล้วแก้ไขไม่ได้ (ล็อกถาวร) · รูปหลักฐานเก็บใน `server/data/pod/` (มัลแวร์-guard: เฉพาะ JPG/PNG/WebP ≤ 5MB)

### CRM Workflow
```
ใบเสนอราคา: ร่าง → ส่งแล้ว → ตกลงราคา / ปัดตก / หมดอายุ
              └── (ส่งแล้ว/ตกลงราคา) ──แปลงเป็นออเดอร์──▶ รอจัดคิว (อัตโนมัติ)
```
- แปลงเป็นออเดอร์ได้เฉพาะ quote ที่ "ส่งแล้ว/ตกลงราคา" และยังไม่เคยแปลง (1 quote = 1 ออเดอร์) · แปลงแล้วล็อกทันที
- การแปลงใช้ **transaction เดียว**: สร้างออเดอร์ + อัปเดตสถานะ quote + ผูกหมายเลขออเดอร์
- ลูกค้าเสี่ยง = เคยมีออเดอร์แต่เงียบไป 30+ วัน (คำนวณอัตโนมัติในรายงาน) · งานติดตามมีวันที่ครบกำหนด + สถานะค้าง/เสร็จ

## 🧱 เทคโนโลยี

- **Backend:** Node.js + Express 5 + TypeScript · SQLite (**better-sqlite3**) · Zod (validation) · JWT (jose) + bcryptjs
- **Frontend:** React 19 + Vite · react-router-dom · SVG charts เขียนเอง · CSS design system + animation (transform/opacity เท่านั้น)
- **Design system v5 (Aurora):** พื้นหลังขาวอมม่วง `#FAF9FD` (ไม่ใช่ขาวล้วน — จ้อง 8 ชม. ไม่ล้า) · periwinkle `#6C7BE8` + violet `#8A6BD1` แบบหม่น · เงาอมม่วง 3 ระดับ (ไม่ใช่เทาดำ) · รัศมีไล่ตามขนาดชิ้นงาน (ปุ่ม 12 · การ์ด 16 · โมดัล 22) · **gradient จำกัด 4 จุดทั้งระบบ** (โลโก้ · avatar · โลโก้ล็อกอิน · เมนูที่เลือก) · ฟอนต์ IBM Plex Sans Thai ตัวเดียว ลำดับชั้นมาจากน้ำหนัก · ตารางสไตล์ Stripe · badge ไร้เส้นขอบ · สี = สถานะเท่านั้น · responsive ถึงมือถือ
- **Design tokens 3 ชั้น** (global → semantic → component) + **motion tokens** (duration/easing) — เปลี่ยนค่าที่ token ที่เดียว · **WCAG 2.2 AA 41/41 คู่สีผ่าน** (ตรวจด้วยสคริปต์อัตโนมัติ — รวมเกณฑ์ 3:1 ของ focus ring/ขอบฟิลด์ตาม 1.4.11)
- **สิทธิ์ระดับแถว (คนขับ):** `drivers.user_id` ผูกบัญชีเข้ากับคนขับ · สิทธิ์ `myjobs.*` ไม่ได้เปิดทั้งตารางแบบสิทธิ์อื่น แต่เปิดเฉพาะแถวที่ `trips.driver_id` ตรงกับคนนั้น · ทุกการกระทำเช็คเจ้าของก่อนเสมอ และตอบ **404 ไม่ใช่ 403** เมื่อไม่ใช่เที่ยวของตัวเอง (403 = ยืนยันว่าเที่ยวนั้นมีอยู่จริง เท่ากับยอมให้ไล่เดาเลขเที่ยวคนอื่น) · คอลัมน์เงิน **ไม่ถูก SELECT** ตั้งแต่ใน repository ไม่ใช่ดึงมาแล้วค่อยลบทีหลัง · บัญชีที่ยังไม่ผูกจะได้ข้อความบอกวิธีแก้ ไม่ใช่หน้าว่าง
- **โมเดลสิทธิ์:** `server/src/core/permissions.ts` เป็นแหล่งความจริงเดียว (รายชื่อสิทธิ์ + ป้ายไทย + คำเตือน + ชุดสำเร็จของบทบาท) · ตาราง `user_permissions` เก็บ **เฉพาะส่วนต่างจาก preset** เพื่อให้เปลี่ยนบทบาททีหลังแล้วยังได้ชุดใหม่ตามจริง · middleware `requirePerm()` **อ่านสิทธิ์จาก DB ทุก request** (ไม่ฝังใน JWT — ไม่งั้นถอนสิทธิ์แล้วไม่มีผลจนกว่า token 12 ชม. จะหมดอายุ) · ปิดบัญชี = token เดิมใช้ไม่ได้ทันที · กันระบบเหลือ admin ศูนย์คน และกันถอนสิทธิ์ `users.manage` ของตัวเอง · web ใช้ `can()` แค่ซ่อน/แสดงปุ่ม-เมนู ไม่ใช่ด่านกันจริง
- **สองรูปแบบบนหน้าเดียว (จอคอม/มือถือ):** จอคอมเห็นทุกอย่างพร้อมกัน (ตาราง + สิทธิ์ทั้ง 12 กลุ่มกางหมด 2 คอลัมน์) · ต่ำกว่า 900px เปลี่ยน**รูปแบบ ไม่ใช่แค่ย่อ** — รายชื่อเป็นการ์ดต่อคน, สิทธิ์เป็นกลุ่มพับได้ทีละกลุ่ม, สวิตช์กดได้ทั้งแถว (สูง 44px ตาม WCAG 2.5.8) · สวิตช์ใช้ `<button role="switch">` ไม่ใช่ checkbox ตกแต่ง
- **โหมดมืด (Aurora กลางคืน):** ปุ่มสลับที่ topbar · ครั้งแรกตาม `prefers-color-scheme` ของเครื่อง แล้วจำใน `localStorage` · ทาธีมด้วยสคริปต์ใน `index.html` ก่อนวาดเฟรมแรก (ไม่กระพริบขาว) · พื้น `#14111F` ไม่ใช่ดำสนิท (ดำสนิท + ตัวอักษรขาว = halation อ่านนานล้า) · สีสถานะสว่างขึ้นทั้งชุด เงาเปลี่ยนเป็นดำ · `color-scheme: dark` ให้ scrollbar/ปฏิทิน/`<select>` ของเบราว์เซอร์เข้มตาม · ทุกคู่สีผ่าน AA (15 คู่ในสคริปต์ contrast)
- **ย่อเมนูข้าง 268 → 78px:** ปุ่มท้าย sidebar หรือ `Ctrl + [` · จำสถานะใน `localStorage` · ตอนย่อ ข้อความซ่อนด้วย `display:none` (ไม่ใช่ opacity — ไม่งั้นไอคอนไม่ตรงกลาง), หัวข้อกลุ่มกลายเป็นเส้นคั่น, badge หดเป็นจุดเกาะมุมไอคอน, hover ขึ้น tooltip
- **ระเบียบตัวอักษรไทย:** ห้าม `text-transform: uppercase` และ `letter-spacing` ติดลบบนข้อความไทย — ไทยไม่มีตัวพิมพ์ใหญ่ และ tracking ทำให้สระ/วรรณยุกต์หลุดตำแหน่ง ความ "เงียบ" ของ label มาจากขนาด+สี ไม่ใช่ tracking
- **หลักเรตติ้งสูง** (อ้างอิง Awwwards/Google 50ms/NN-g): แถบเมตริกเดียว (3–4 KPI ใน 1 การ์ด แบ่ง hairline) ลด visual complexity, รายการ AI แบนไร้กล่องซ้อน, count-up + tabular-nums (เฉพาะจุดที่เป็นตัวเลข), hero ทักทาย 22px น้ำหนัก 660, spacing 40px — ดู docs/ROADMAP-2026.md §2.5
- **กติกาตาราง (กันหน้าจอ "เลอะ"):** เลขที่เอกสาร/วันที่/จำนวนเงิน = `nowrap` เสมอ (`.cell-no` `.cell-date` `.num`) · หัวการ์ดกับคำอธิบายอยู่คนละบรรทัด · ปุ่มท้ายแถวห่อบรรทัดแทนล้น · **คอลัมน์ ≤ 8** — ข้อมูลรองไปอยู่บรรทัดที่สองของเซลล์หลัก ไม่ตั้งคอลัมน์ใหม่ — ดู docs/ROADMAP-2026.md §3.6
- **BOL + ส่งออกรายงาน:** ใบนำส่ง (BOL) — `GET /api/orders/:id/bol` (ออเดอร์+ลูกค้า+รถ+คนขับ+ชื่อองค์กร) → โมดัล A4 + พิมพ์ได้ · Excel — เขียน `.xlsx` เองไร้ dependency (`server/src/utils/xlsx.ts`: zip STORE + SpreadsheetML, 9 ชีต ตัวเลขเป็นตัวเลขจริง) · PDF — `window.print()` + print CSS (ซ่อน chrome ของแอป)
- **ชุดไฟล์สำเร็จรูปทั้งระบบ (ไม่ต้องรัน server):** `web-static/` — ไฟล์เดียว `index.html` เหมือนระบบจริง (SPA: sidebar + topbar + สลับหน้าในหน้าจอเดียว) + แยกโฟลเดอร์ **`css/styles.css`** (design system) **`js/app.js`** (นำทาง/สลับหน้า) **`js/pages.js`** (เนื้อหาทุกหน้า ข้อมูลจริงฝังในไฟล์) + **`เอกสาร/`** (เทมเพลตใบนำส่ง/รายงาน) + **`ข้อมูล/`** (ข้อมูล 9 ตารางเป็น CSV) + README อธิบายทุกไฟล์ — เปิด `index.html` ได้เลย พิมพ์ได้ · regenerate ทั้งชุด: `npm run static:export`
- **เทมเพลตเอกสาร (ใช้โดยไม่ต้องรัน server):** `server/data/templates/` — `bol-form.xlsx` (แบบฟอร์มใบนำส่งเปล่า มีเส้นขอบ+หัวส่วน พิมพ์/กรอกใน Excel ได้), `report-template.xlsx` (เทมเพลตรายงาน 9 ชีต หัวตารางครบตรงกับหน้า export — เอา CSV จาก `server/data/csv/` มาแปะได้), `bol-form.html` (แบบฟอร์ม BOL กรอกในเบราว์เซอร์ + ปุ่มพิมพ์ — เปิดไฟล์ double-click ได้เลย ไม่ต้อง server) · regenerate: `npm run static:templates`
- **CSV export layer:** DB (SQLite) = แหล่งข้อมูลเดียว จัดการผ่านเว็บ · ทุกตารางธุรกิจ = 1 ไฟล์ CSV ใน `server/data/csv/` (เรียงเลขตาม foreign key, BOM+CRLF → Excel เปิดไทยถูก) · **export ทิศเดียว DB → CSV** เขียนใหม่ทุก 3 วิเมื่อข้อมูลเปลี่ยน · แก้ไฟล์ตรง ๆ → ระบบเขียนทับกลับ (ไม่อนุญาตให้แก้ข้อมูลผ่านไฟล์) · ดาวน์โหลดได้จากหน้า "ข้อมูล CSV" + กัน path traversal · อธิบายแต่ละไฟล์ใน `server/data/csv/README.md`
- **ขนาด bundle:** ~110KB gzip — code-split ตามหน้า, ไม่มี dependency หนัก, `prefers-reduced-motion` รองรับ

```
  ├─ middleware/          # auth (JWT+roles) · validate (zod) · errorHandler กลาง
  ├─ modules/<โมดูล>/     # 13 โมดูล · 4 ชั้น: route → controller → service → repository
  │                       #   auth customers vehicles drivers orders trips pod myjobs

  ├─ components/          # design system (ui.tsx) + charts.tsx + icons.tsx + Layout
  │                       #   + BolModal · PodModal · SignaturePad
  ├─ pages/               # 13 หน้า (lazy-loaded: ล็อกอิน, ภาพรวม, แผนงาน, ออเดอร์,
  │                       #   ใบเสนอราคา, ลูกค้า, ลูกค้า detail, รถ, คนขับ, รายงาน,
  │                       #   ข้อมูล CSV, ตั้งค่า, 404)

  ├─ hooks/ · context/ · styles/ (tokens → base → components → animations)
  └─ scripts/contrast.mjs # ตรวจ WCAG contrast ทุกคู่สี
```

## 🚀 เริ่มใช้งาน

### เปิด/ปิดแบบง่ายที่สุด (ย้ายเครื่องก็ใช้ได้)
**เครื่อง Windows ที่ยังไม่มี Node ก็กด `start.cmd` ได้เลย** — สคริปต์จะติดตั้ง Node LTS แบบ portable
ลง `%LOCALAPPDATA%\nodejs` ให้เอง (มีแถบ %, ตรวจ SHA256, เพิ่มเข้า PATH ของผู้ใช้) **ไม่ต้องใช้สิทธิ์ admin
และไม่ต้องปิด-เปิดหน้าต่างใหม่** จากนั้นทำต่อให้ครบเอง: ติดตั้ง dependencies → build → สร้างฐานข้อมูล

ออฟฟิศที่บล็อก nodejs.org: ตั้ง `NODE_MIRROR` ชี้ mirror ภายในก่อนรัน

| ระบบ | เปิด | ปิด |
|---|---|---|
| Windows | double-click `start.cmd` | double-click `stop.cmd` |
| macOS / Linux | `./start.sh` | `./stop.sh` |
| ทุกระบบ (terminal) | `npm run serve` | `npm run serve:stop` |

```bash
npm run serve          # เปิด (พร้อมบอก URL ของเครื่องอื่นในวง LAN)
npm run serve:stop     # ปิด
npm run serve:restart  # เปิดใหม่
npm run serve:status   # เช็คว่าเปิดอยู่มั้ย
```
- server ทำงานเบื้องหลัง — ปิดหน้าต่าง terminal แล้วยังรันอยู่ ต้องสั่ง stop เท่านั้น
- log อยู่ที่ `.run/server.log` · pid อยู่ที่ `.run/server.pid`
- เปลี่ยน port: `PORT=3200 npm run serve` (Windows PowerShell: `$env:PORT=3200; npm run serve`)
- ⚠️ ก่อนใช้งานจริง ตั้ง `JWT_SECRET` เป็นค่าลับของตัวเองใน `.env` — ค่า default เป็นค่าสำหรับ dev เท่านั้น

**เปิดเป็น HTTPS โดยค่าเริ่มต้น** (`https://localhost:3100`) ไม่ใช่เรื่องความปลอดภัยอย่างเดียว
แต่เป็นข้อบังคับของเบราว์เซอร์: **กล้องของคนขับและ GPS ทำงานเฉพาะ secure context** —
เปิดผ่าน `http://192.168.x.x` เบราว์เซอร์จะไม่ให้ใช้กล้องเลย

- ใบรับรองสร้างเองอัตโนมัติที่ `server/data/cert/` ครอบคลุม IP ทุกใบของเครื่อง และออกใหม่เองเมื่อ IP เปลี่ยน
- เปิดจากมือถือครั้งแรกจะเตือน "ไม่ปลอดภัย" — กดยอมรับได้ ถ้าเบราว์เซอร์ไม่ยอมให้ใช้กล้อง
  ให้ส่ง `server/data/cert/cert.pem` ไปติดตั้งให้เครื่องเชื่อถือ (iOS ต้องเปิดใน
  Settings › General › VPN & Device Management **แล้วเปิดใน Certificate Trust Settings อีกจุด**)
- อยู่หลัง reverse proxy ที่ทำ TLS ให้แล้ว: ปิดด้วย `HTTPS=0`

## 📱 ติดตั้งเป็นแอปบน iPhone / iPad

### วิธีที่ 1 — PWA (ติดตั้งที่หน้า Home ได้เลย ไม่ต้องใช้ Mac)
ระบบเป็น **Progressive Web App** อยู่แล้ว (manifest + service worker + ไอคอน):
```bash
npm run build && npm start        # หรือ deploy ขึ้น server ที่มี HTTPS
```
จากนั้นบน iPhone/iPad เปิด Safari เข้า URL ของระบบ → กดปุ่ม **แชร์ (Share) → "เพิ่มที่หน้าจอหลัก" (Add to Home Screen)**
ระบบจะติดตั้งเป็นแอปเต็มจอ (ไร้แถบเบราว์เซอร์) มีไอคอนอำพัน เปิดออฟไลน์ได้ (shell cache)
> หมายเหตุ: เปิดผ่าน **Safari เท่านั้น** (iOS ไม่อนุญาตให้ Chrome ติดตั้ง PWA) และควรใช้ HTTPS (localhost/เครือข่ายในบ้าน ใช้ได้โดยไม่ต้องมี)

### วิธีที่ 2 — แอป App Store จริง (Capacitor)
โปรเจกต์ iOS ถูก scaffold ไว้แล้วใน `web/ios/` (สร้างด้วย Capacitor 7):
```bash
# 1. สร้าง frontend แล้ว sync เข้าโปรเจกต์ iOS
VITE_API_BASE=https://tms.example.com npm run build -w web   # ชี้ API ไป server ที่ deploy จริง
npx cap sync -w web

# 2. นำโฟลเดอร์โปรเจกต์ไปเครื่อง macOS ที่ติดตั้ง Xcode แล้วเปิด
npx cap open ios        # เปิด Xcode → เลือก Team ของ Apple Developer → กด Run/Archive
```
สิ่งที่ต้องมี (นอกเหนือจากโค้ดนี้): **macOS + Xcode + บัญชี Apple Developer ($99/ปี)** สำหรับลงนามและส่งขึ้น App Store
ถ้าเปิดใช้แค่ในทีม (ไม่ต้องผ่าน App Store) ใช้ **Apple Developer Program ฟรี** + วิธี "Device Management" บน iPhone ได้
> ⚠️ ก่อนขึ้น App Store: เปลี่ยน `appId` ใน `web/capacitor.config.ts` ให้ตรงกับ bundle id ที่ลงทะเบียนไว้

### หนี้ทางเทคนิคที่รู้อยู่
- แถวใบเสนอราคาสถานะ "ส่งแล้ว" มีปุ่ม 4 ตัวเรียงลง — แก้จริงต้องมีคอมโพเนนต์ dropdown ซึ่งยังไม่มี
- `StatCard` ไม่มีหน้าไหนเรียกใช้แล้ว (มี a11y test คุมอยู่) — ยังไม่ลบ
- `web/src/pages/CustomerDetail.tsx` ยังมี inline style ~31 จุด ที่ควรยกเป็นคลาส
- `web-static/` เป็น snapshot — ต้องรัน `npm run static:export` ใหม่ทุกครั้งที่ UI หรือข้อมูลเปลี่ยน
- **`better-sqlite3` ค้างที่ `^12.x` โดยตั้งใจ** — v13.0.3 ไม่ปล่อย prebuilt binary เลย เครื่องที่ไม่มี Visual Studio C++ (คือเครื่องออฟฟิศทั่วไปที่ไม่มีสิทธิ์ admin) จะติดตั้งไม่ผ่านเพราะต้อง compile ด้วย node-gyp · อัปเป็น 13 ได้ต่อเมื่อ upstream กลับมาปล่อย prebuild
- **ใบรับรอง TLS เป็น self-signed** — พอสำหรับใช้ในวง LAN แต่มือถือคนขับต้องกดยอมรับ (หรือติดตั้ง cert) ครั้งแรก · ถ้าเปลี่ยนวง Wi-Fi แล้ว IP เปลี่ยน ระบบจะออกใบใหม่ให้ ต้องกดยอมรับใหม่รอบหนึ่ง — แก้ถาวรด้วยการขอ DHCP reservation จากฝ่าย IT
- POD ยังเก็บได้ **รูปเดียวต่อออเดอร์** และเก็บได้เฉพาะตอนส่งสำเร็จแล้ว (ยังถ่ายตอนรับของไม่ได้) — ดู `docs/PLAN-driver-photo.md` เฟส 2–3
- `signature_data` เก็บเป็น data URL ในตาราง `pod` ทำให้ไฟล์ DB โตเร็วกว่าที่ควร ควรย้ายไปเป็นไฟล์เหมือนรูป
