# รูปต้นฉบับของไอคอนแอป

วางไฟล์ `logo.png` ไว้ในโฟลเดอร์นี้ แล้วรัน:

```bash
npm run icons -w web
```

สคริปต์จะย่อ/ขยายเป็นไอคอนทุกขนาดให้เอง (192 / 512 / maskable / apple-touch-icon 180)
แล้ววางผลลัพธ์ที่ `web/public/icons/`

ข้อกำหนดของไฟล์ต้นฉบับ:

- **PNG 8 บิตต่อช่อง** (ค่าปกติของโปรแกรมแต่งรูป) ไม่ใช่แบบ interlace
- **ด้านสั้นสุดควรไม่ต่ำกว่า 512px** เล็กกว่านั้นขยายแล้วเบลอบนจอความละเอียดสูง
- พื้นหลังโปร่งใสได้ สคริปต์วางพื้นสีของธีมให้เอง
- รูปไม่จำเป็นต้องเป็นจัตุรัส สคริปต์วางกลางกรอบและคงสัดส่วนเดิมไว้

ไม่มีไฟล์นี้ก็รันได้ — สคริปต์จะถอยไปวาดรถบรรทุกด้วยโค้ดแทน
