# แอปคนขับ (iOS)

เปลือก Capacitor ที่ห่อหน้าเว็บเดิมไว้ ไม่มีโค้ดหน้าจอของตัวเอง — ทุกจอมาจาก
`web/dist` ก้อนเดียวกับที่ขึ้นเว็บ แก้หน้าคนขับที่ `web/src` แล้ว sync ใหม่

## ทำไมต้องมี

PWA บน iOS หยุดเก็บพิกัดทันทีที่ล็อกจอ คนขับล็อกจอเกือบตลอดเวลาที่ขับ
เส้นทางจึงขาดเป็นช่วง ๆ แอป native ขอสิทธิ์ `location` แบบเบื้องหลังได้
นั่นคือเหตุผลเดียวที่คุ้มจะห่อ ส่วนกล้อง ลายเซ็น และรูปภาพ PWA ทำได้ครบอยู่แล้ว

## ลำดับคำสั่ง

```
npm run ios:sync      # build web + คัดลอกเข้า ios-driver/www + cap sync
```

จากรากโปรเจกต์ ทำได้บน Windows ทั้งหมด

## build จริงต้องใช้ macOS

Xcode มีแต่บน macOS เครื่องที่พัฒนาเป็น Windows จึง build ที่นี่ไม่ได้
ใช้ `.github/workflows/ios-driver.yml` แทน — สั่งเองได้จากแท็บ Actions
(workflow_dispatch) ผลลัพธ์เป็น `.ipa` **ที่ยังไม่เซ็น** แนบไว้เป็น artifact

## ลง `.ipa` ที่ยังไม่เซ็นลงเครื่อง

ต้องเป็นเครื่องที่ปลดล็อกแล้ว วิธีขึ้นกับเลข iOS ของเครื่อง เครื่องที่ยังไม่ได้
ปลดล็อกต้องเซ็นก่อนด้วยบัญชี Apple Developer ซึ่งยังไม่มี

## พิกัดเบื้องหลัง

`@capacitor-community/background-geolocation` ต่อไว้แล้ว ตัวเชื่อมอยู่ที่
`web/src/api/bgGeo.ts` — ที่เรียกใช้ไม่ต้องรู้ว่ากำลังอยู่บนแอปหรือบนเว็บ
บนเว็บมันถอยไปใช้ `navigator.geolocation` ตัวเดิม พฤติกรรมเท่าเดิมทุกอย่าง

`cap sync` มองเห็นปลั๊กอินแล้ว (`Found 1 Capacitor plugin for ios`) แต่โค้ดฝั่ง
native **ยังไม่เคยรันจริงสักครั้ง** เพราะ build ต้องใช้ macOS ที่ยังไม่มี
ทางเว็บทดสอบแล้วว่าไม่พัง ทางแอปเป็นการรอพิสูจน์

## สิ่งที่ยังไม่ได้ทำ
- ยังไม่ได้ล็อกให้เปิดมาที่จอคนขับโดยตรง ตอนนี้เปิดมาเจอหน้าล็อกอินเดียวกับเว็บ
  ซึ่งใช้ได้ แต่คนขับเห็นเมนูของออฟฟิศด้วยถ้าบัญชีมีสิทธิ์
- ไอคอนกับหน้า launch ยังเป็นของตั้งต้นจาก Capacitor
